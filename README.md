# ADS1015-CYCLONE-IV-MAX7219
This project utilizes the second ADC channel. Averaging and median filters are 
implemented. The input voltage range is from 0.0 volts to 3.3 volts. The display 
displays values ​​from 0.000 to 3.300.
Quartus Prime Lite Edition 25.1.
FPGA Altera Cyclone EP4CE6E22C8.
Ads1015  addr 90H pin addr connect to gnd.
